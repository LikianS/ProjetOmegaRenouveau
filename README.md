# Portage VR — Projet d'Infographie

## Description

Portage en réalité virtuelle d'un jeu Unity, développé dans le cadre d'un projet de semestre. Le projet inclut un système d'immersion IK, un déplacement au joystick, des énigmes adaptées à la VR (miroirs laser, reconstitution d'armure) et une interface repensée pour le casque Meta Quest 3.

## APK

Deux APK ont été générées pour le Meta Quest 3, mais **elles ne sont pas vraiment utilisables** en l'état en raison de problèmes de performances non résolus. Le jeu souffre d'un bottleneck GPU qui empêche d'atteindre les 72 FPS stables requis pour une expérience VR confortable.

Les APK sont fournies à titre de démonstration de l'avancement technique du projet.
